## What I'm working on

### Numyn Software

Through **[Numyn Software](https://numyn.ca)**, I develop software for small businesses and offer software development and IT services.

My main product, **Numyn**, is a local bookkeeping application built with **Python, Flask, and SQLite**. It grew out of tools I built for my own collectibles business, K-Games & Collectables, and brings together income and expenses, invoicing, GST/HST tracking, reporting, and exports.

I'm preparing it for a licensed public release, with work focused on liability tracking, simpler settings, packaging, and an easier setup experience. The initial release is **targeted for Q1 2027, with a possible move to Q2 as development and testing progress**. Optional inventory, tax support, payroll, and industry-specific tools are longer-term roadmap items.
